**Full write-up:** [Read the PDF Write-up (Browser Viewer)](https://docs.google.com/viewer?url=https://github.com/Ardeshir-Aidun/Ultrasonic-Sensor-Characterization/raw/main/Ultrasonic_Sensor_Accuracy_Noise_Characterization_Writeup.pdf)

- `ultrasonic_test_no_lcd.ino` — Arduino sketch for data collection
- `log_and_analyze.py` — Python logging + analysis script
